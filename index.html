Straight answers

Read this before you order.

Why is it this cheap?

Because you're paying for a slot in a batch, not for something already sitting in a US warehouse. No domestic overhead, no fast shipping, no card processing. The discount is your compensation for the wait.

How long actually?

Plan on 4–6 weeks. Most land inside that. Customs is the variable — if a batch gets held it can run longer, and we'll tell you rather than guess.

What if customs seizes it?

One free reship on the same lines, no argument. Reships go into the next batch, so add the transit time again.

Do I need a prescription?

No. Nothing here needs a script or a telehealth call. You order, you get the compound, dosing is on you.

Is there a minimum?

$40 per order before discount. No minimum quantity per line.

Can I mix categories?

Yes. The basket takes anything, and discounts apply per line, so a mixed order still gets the ladder on each line that qualifies.

Which coins?

BTC, ETH, USDT, USDC, SOL, XMR, LTC. We quote one coin per order and hold the rate 15 minutes.

Can I get a refund?

Crypto is one-way, so refunds are credited against a future order rather than sent back. Cancellations before the batch seals are fine.

Do you ship outside the US?

US only for now. Message us if you're elsewhere and we'll tell you straight whether it's worth it.
